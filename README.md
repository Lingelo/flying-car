# Flying Car — Neon City

Bac à sable Three.js : une voiture volante dans une ville cyberpunk infinie générée procéduralement.

Plan produit et technique : [`docs/plans/2026-10-18-1313-feat-cyberpunk-flying-car-sandbox-plan.md`](docs/plans/2026-10-18-1313-feat-cyberpunk-flying-car-sandbox-plan.md).

```bash
npm install
npm run dev        # http://localhost:5173
```

## Vérifier

```bash
npm run typecheck
npm test
npm run build
```
